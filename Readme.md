# TIMELESS

**Minimalism That Doesn't Distract.**

This is not just a timer. This is a tool for mindfulness. No cluttered numbers, no flashing panels, no overwhelming settings. Just you and pure time.

---

## Features

- **Aesthetics of Silence** — A clean interface with refined shadows and bold typography. Nothing extra.
- **Tactile Control** — Circular progress and intuitive gestures for start and pause.
- **Completion Signal** — When time runs out, you won't miss it. A subtle sound alert plays, gently bringing you back to the present.
